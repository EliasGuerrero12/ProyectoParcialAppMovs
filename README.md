**D e s c r i p c i ó n**

Aplicación móvil desarrollada en .NET MAUI como parte del primer parcial de la materia 
Aplicaciones Móviles. La app funciona como una fan page del artista argentino Milo J,
mostrando información sobre su biografía, discografía, conciertos y detalles de álbumes.



**R e q u i s i t o s**

**Visual Studio 2022 con workload de .NET MAUI instalado**

**P a s o s  E j e c u c i ó n**

Clonar el repositorio

bash
git clone [URL del repositorio]
cd AppMovilesParcial1

Abrir el proyecto
Abrir Visual Studio 2022
Seleccionar "Abrir un proyecto o solución"
Navegar a la carpeta clonada y seleccionar AppMovilesParcial1.sln

Presionar F5 o el botón "Play" para compilar y ejecutar

Ejecutar la aplicación
